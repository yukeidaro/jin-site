How it works

An AI harness is the instructions, skills, memory and connected tools around an AI agent that make it work for a role.

Employee

  1. Connect once.

    Jin AI connects to your AI tools through MCP.

  2. See every harness by category.

    Skills, instructions, memory and MCP settings, sorted for each person.

    For example: CLAUDE.md, skills, memory files and MCP settings.

Admin

  1. See it by role.

    Which harnesses each role uses, and how often.

  2. Decide what can move.

    Parts marked confidential connect only to the AI tools you approve.

    In pilots, the company approves by hand today.

Your company's context stays yours.

  • Each company's context is kept separate.
  • Jin AI never records your screen.
  • Jin AI itself never trains on your data.
