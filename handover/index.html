Your best AI harness lives on one laptop

Months of tuning sit in one engineer's home directory. Teammates cannot see it, read it, or run it. When that engineer changes teams or leaves, it goes with them.

How Jin Handover works

  • Connect

    Import an existing Claude Code environment, including user-level files that never reach a repo.

  • Understand

    Jin AI sorts the harness by type and summarizes what each part does and what is reusable.

  • Hand over

    An authorized teammate reviews the approved harness and connects it to their own tools.

Why not just a Git repo

Keep the repo. Claude Code already reads project files and skills from it. Jin Handover covers what never gets there.
