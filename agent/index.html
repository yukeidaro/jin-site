Structured for AI. Simple for people.

AI agents now write your files for you — Markdown, decks, documents, spreadsheets and PDFs — and file them somewhere you would not have. Jin AI puts that structure on one screen, lets you correct it, and records every change, so yours and the agent's can be undone separately.

You lose the file twice

First you forget what it was called. Then you forget where it went.

Each agent may create files according to its own logic. Instructions, memory, logs and intermediate output sit beside the Markdown, decks, documents, spreadsheets and PDFs a person actually needs to deliver. Work becomes split across editors, chats, slides and documents, and the person loses track of what changed where.

Evidence and caveats

ObservationResultScope and source
Agent-generated Markdown files 3,950 files in one week; 89% were not reopened within a week; 283 were named README.md. One founder's laptop only. Not market-wide evidence. We have not surveyed anyone else yet.
How people reach files Navigation: 56–68%. Search: 4–15%. The pattern barely changed after search tools were upgraded. Bergman et al., ACM Transactions on Information Systems, 2008.

Visible, editable, reversible

Jin AI does not change how agents work. It makes the structure easier to see, correct and maintain.

See

See the whole project at once

View the same files by project, person, recency, topic, date or file type. The files do not move.

Fix

Move things like normal files

Rename, move, regroup or hide an item directly when an agent places it somewhere you would not have.

Undo

See what changed and change it back

Human changes and each agent's changes are recorded separately, so the wrong part can be reversed.

The agent can still reach everything. You just do not need to see everything.

How structural decisions reach agents

Jin AI writes the user's structural decisions back into the instruction files agents already read: CLAUDE.md, AGENTS.md and copilot-instructions.md. There is no plugin and no API requirement. The files remain Markdown so existing agents continue to work.

What it looks like

See your work as a workspace, then open a page and get to work.

Visual workspace

Clear projects and subprojects show meetings, research, decisions and deliverables on one screen.

Visual Markdown editor

People edit and reorganise content without learning Markdown syntax, GitHub or developer tools.

Human-relevant view

Documents people need are separated from agent-only instructions, memory, logs and intermediate outputs.

One page per subject

Notes, decisions, PowerPoint files, PDFs and links sit together, with Markdown remaining the spine.

Both sides get what they need

People stop managing files

Attention goes to moving the work forward instead of hunting, renaming and deciding where files belong.

AI gets richer context

Agents retain relationships, sources and history without pushing the same volume of information at people.

Free on your laptop. Paid when it leaves.

Individuals pay only to share or to store in the cloud. Companies buy seats.

  • Individual local use: free; no account; files stay on the device in plain Markdown.
  • Individual collaboration: planned at $15 per month, plus usage-based cloud storage.
  • Companies: per-seat enterprise pricing for shared workspaces, secure storage, governance and audit.
  • Pricing status: company pricing is not final and will be validated with early customers.
