Direct answer

Jin AI is a visual workspace for the files AI agents create, with Markdown as the spine. It is for business users working with AI agents and is currently in build.

Problem

Your agents decide and you are not asked. Agents create, rewrite and file documents on your own machine, choosing the structure without approval and without reporting what changed.

Each agent creates files according to its own logic, on the user's own machine, picking folders without asking and without reporting what changed. The user loses both visibility and control, and because the output is never visible it cannot be corrected, so the same problem repeats.

Evidence and limits

On one founder's laptop, agents created 3,950 Markdown files in one week; 89% were not reopened within the following week; 283 were named README.md.

Scope: One founder's laptop only Caveat: This is not market-wide evidence. Jin AI has not surveyed anyone else yet.

Source: Internal observation.

Participants estimated that they reached files by navigation 56–68% of the time and by search 4–15%, with little change after search tools were improved.

Scope: Desktop personal-information-management studies; not research on AI-generated files or Jin AI users.

Planned product behavior

You decide where things go, not the agent. The agent can still reach everything. You just do not need to see everything.

See

Read the actual files an agent created or changed, grouped by project, person, recency, topic or file type, without moving anything.

Fix

Put an item where it belongs by renaming, moving, regrouping or hiding it when an agent filed it somewhere a person would not have.

Undo

Roll back an individual agent's change without touching your own edits, because the two are recorded separately.

Direct questions and answers

What is Jin AI?

Jin AI is a visual workspace for the files AI agents write on your own computer. It is being built to give you control of that output: see what an agent created and changed, put it where it belongs, undo an individual agent's edit, and have those decisions written into the instruction files agents already read.

Who is Jin AI for?

Jin AI is for business users who work with AI agents but do not want file names, folders, links, tags, Markdown syntax or developer tools to become a second job.

Why not just look in my file explorer?

A file explorer shows names and dates, not what an agent produced or changed. It does not separate agent-only files from your deliverables, and it cannot tell you which agent made which edit.

Does Jin AI replace Markdown?

No. Markdown remains the spine so agents can keep working. The planned visual interface means people will not need to learn Markdown syntax.

Does Jin AI move or upload local files?

The planned local edition is designed to read files in their existing locations without moving them. Sharing and cloud storage are optional planned paid capabilities.

How does Jin AI make my agents better?

Your decisions become the rules. A planned next capability will write your structural decisions into CLAUDE.md, AGENTS.md and copilot-instructions.md, which agents already read, so the next file lands where you would have put it. No plugin or API is planned to be required.

Is Jin AI available now?

Not yet. Jin AI is in build and early access is planned to open in small batches.

How much will Jin AI cost?

Individual local use is planned to be free. Individual collaboration is planned at $15 per month plus usage-based cloud storage. Company pricing is not final.

Business model

Free on your laptop. Paid when it leaves. Planned to be free, with no account required and files remaining on the device in plain Markdown. Planned at $15 per month, plus usage-based cloud storage. Planned per-seat enterprise pricing for shared workspaces, secure storage, governance and audit.

Not final; to be validated with early customers.
