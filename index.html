The problem

Your agents decide. You are not asked.

An agent reports that the task is done. Somewhere on your disk it created files, rewrote others and picked the folders they live in. You did not watch it happen and nothing handed you a list. You find out later, when you need the file or when something is wrong. And because you never see the output, you cannot tell the agent to do it differently. So the same thing happens again tomorrow.

“I edited an MD file in Codex and wanted to use it in a meeting later. When I came back I couldn’t remember what the file was called, or where it was.”

Nothing recorded what the agent produced, so the only record of it was the person’s memory.

“That is not where I would have put it.”

The agent decided the structure. Nobody approved it, and nobody was told.

“You end up opening files one by one just to work out what you made.”

There is no summary of what an agent produced, so people rebuild it by hand.

The solution

You decide where things go. Not the agent.

Jin AI is being built so it does not change how your agents work. It will read the folders they already write to and draw what is in them. The files stay on your machine, in place, in the format your agents expect. What changes is who is in charge of the structure.

See

Every file, grouped the way you think

By project, by person, by what changed today. Open the actual document and read it, instead of guessing from a filename. Nothing is hidden from you because an agent chose an odd folder.

Fix

Put things where they belong

Rename it. Move it. Regroup the project. When an agent puts something in the wrong place, you drag it to the right one. You are not rebuilding a folder tree by hand.

Undo

Undo an agent’s change, not your own

“Claude Code updated this file 3 minutes ago — 2 changes.” Your edits and each agent’s edits are recorded separately, so you can read the change and roll back just that part.

The agent can still reach everything. You just don’t need to see everything. Jin AI is designed not to delete anything or hide files from the agent. It will give people a cleaner view of the files that matter to them, while the agent keeps working with the full project in the background.
Planned next: your decisions become the rules your agents follow. Move a project boundary, rename a category or hide something, and Jin AI will write that decision into the instruction files your agents already read: CLAUDE.md, AGENTS.md, copilot-instructions.md and the rest. The next file an agent writes lands where you would have put it. No plugin and no API. Just the Markdown they are reading anyway. You will not need to open CLAUDE.md. Jin AI is being designed to keep it correct.

Why the structure, and not a better search box: people reach their files by navigating 56–68% of the time and by searching 4–15% — and that barely moved even after their search tools were upgraded. Bergman et al., ACM TOIS, 2008. Desktop personal-information-management studies; not research on AI-generated files or Jin AI users.

Direct answers

The questions people ask first.

Where the product actually is today, what it will cost, and what it does not do.

What is Jin AI?

Jin AI is a visual workspace for the files AI agents write on your own computer. It is being built to give you control of that output: see what an agent created and changed, put it where it belongs, undo an individual agent's edit, and have those decisions written into the instruction files agents already read.

Who is Jin AI for?

Jin AI is for business users who work with AI agents but do not want file names, folders, links, tags, Markdown syntax or developer tools to become a second job.

Why not just look in my file explorer?

A file explorer shows names and dates, not what an agent produced or changed. It does not separate agent-only files from your deliverables, and it cannot tell you which agent made which edit.

Does Jin AI replace Markdown?

No. Markdown remains the spine so agents can keep working. The planned visual interface means people will not need to learn Markdown syntax.

Does Jin AI move or upload local files?

The planned local edition is designed to read files in their existing locations without moving them. Sharing and cloud storage are optional planned paid capabilities.

How does Jin AI make my agents better?

Your decisions become the rules. A planned next capability will write your structural decisions into CLAUDE.md, AGENTS.md and copilot-instructions.md, which agents already read, so the next file lands where you would have put it. No plugin or API is planned to be required.

Is Jin AI available now?

Not yet. Jin AI is in build and early access is planned to open in small batches.

How much will Jin AI cost?

Individual local use is planned to be free. Individual collaboration is planned at $15 per month plus usage-based cloud storage. Company pricing is not final.
