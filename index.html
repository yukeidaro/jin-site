Jin AI is a visual workspace for AI-generated work, with Markdown as the spine.

AI agents now write your files for you — Markdown, decks, documents, spreadsheets, PDFs — and file them somewhere you would not have. Jin AI is being built to put that structure on one screen, let you correct it, and record every change, so yours and the agent’s can be undone separately.

The problem

You lose the file twice.

You can’t remember what the file was called, or where it was saved. When you want to fix something, you open folder after folder looking for it. And the work never happens in one place — you go back and forth between your editor, your chat, your slides and your documents, until you no longer know what you did where.

“I edited an MD file in Codex and wanted to use it in a meeting later. When I came back I couldn’t remember what the file was called, or where it was.”

“That is not where I would have put it.”

So the afternoon goes on moving files and cleaning up folders that an agent made in a second.

“You end up opening files one by one just to work out what you made.”

Agents create and edit quickly. The filenames and the folder structure are what get lost.

The solution

Visible, editable, reversible.

Jin AI is being built without changing how your agents work. It will make the structure easier to see, let you correct it by hand, and let agents help maintain it in the background.

See

One set of files, many ways to see it

By project, by person, by what you used last — the same files, shown the way you need them right now. Jin AI is designed to sort them in the background, so you will not need to move a file or write a tag yourself. Related files will sit beside whatever you have open.

Fix

Move things around like normal files

Rename a file. Move it. Change the folder. Reorganise a project. When an agent puts something in the wrong place you will drag and drop it, instead of rebuilding the structure from scratch.

Undo

See what changed, and change it back

“Claude Code updated this file 3 minutes ago — 2 changes.” Your changes and each agent’s will be recorded separately. If something is wrong, you will be able to check exactly what changed and undo just that part.

The agent can still reach everything. You just don’t need to see everything. Jin AI is designed not to delete anything or hide files from the agent. It will give people a cleaner view of the files that matter to them, while the agent keeps working with the full project in the background.

The product

What it looks like.

See your work as a workspace, then open a page and get to work. Nothing asks you to learn Markdown or move your files anywhere — they stay exactly where they are, in the format your agents expect. Jin AI just draws them, so you find things by recognising them. There is nothing new to learn, either: it looks like the file browser you already know — only what it can do is new.

The visual workspace

See the whole project at a glance

Pages and files stay organised in a structure that makes sense. Meetings, research, decisions and deliverables lay out as one map you can take in without opening anything.

The page

Everything about one thing, together

Notes and decisions are written in Markdown, while PowerPoint files, PDFs and links sit alongside them, so the next agent can pick up where you left off.

A visual editor for Markdown

Edit, reorganise, duplicate and connect content directly. Everything you do is written back as ordinary Markdown, so nothing you touch becomes unreadable to an agent.

Planned: agent-only files, out of sight

The planned separation will keep instructions, memory, logs and intermediate output on disk and available to agents without placing them in your default view.

The outcome

Both sides get what they need.

The point isn't a tidier folder. It's that the two audiences for your work stop pulling against each other.

People stop managing files

You spend your attention on moving the work forward instead of hunting for the right version, renaming things and deciding where they belong. The structure is still there — you just aren't the one maintaining it.

AI gets richer context

Agents can see relationships, sources and history across everything you've produced, without that same volume being pushed at you. More context for them does not have to mean more noise for you.

Direct answers

Questions people and agents ask first.

Current product status, scope and pricing without launch-stage ambiguity.

What is Jin AI?

Jin AI is a visual workspace for AI-generated work, with Markdown as the spine. It is being built to show business users the structure their agents created, let them correct it, and record human and agent changes separately so either can be undone.

Who is Jin AI for?

Jin AI is for business users who work with AI agents but do not want file names, folders, links, tags, Markdown syntax or developer tools to become a second job.

Does Jin AI replace Markdown?

No. Markdown remains the spine so agents can keep working. The planned visual interface means people will not need to learn Markdown syntax.

Does Jin AI move or upload local files?

The planned local edition is designed to read files in their existing locations without moving them. Sharing and cloud storage are optional planned paid capabilities.

How will agents learn the structure a person chose?

A planned next capability will write structural decisions into CLAUDE.md, AGENTS.md and copilot-instructions.md, which agents already read. No plugin or API is planned to be required.

Is Jin AI available now?

Not yet. Jin AI is in build and early access is planned to open in small batches.

How much will Jin AI cost?

Individual local use is planned to be free. Individual collaboration is planned at $15 per month plus usage-based cloud storage. Company pricing is not final.
